# harness-2048 每日同题种子局——设计文档

> 2026-11-18 人裁收口（brainstorming 产出）。书《Harness 工程：Codex 智能游戏开发入门》ch7 配套仓。

## 意图与为什么

把 harness-2048 从骨架写成**完整可玩**的 2048，突出点只有一个：**每日同题种子局**——全网玩家同一天拿到完全相同的开局与出牌序列，玩的是「同一道题谁走得好」，不是运气。本书教学母题「可复现=可验证」由种子化随机数天然承载：同种子→同序列→断言可写死→书稿代码块可直接引用。教学坡度上 ch7 是入门游戏第一课，规则集取最简形态（每天 1 局）。

## 目标

- 完整经典 2048 玩法：4×4、四向滑动、同值合并一次一步、每步生成一张 2 或 4（概率 9:1）、无路可走判负、合成 2048 达成胜利（可继续冲分）
- 每日一题：种子=UTC+8 日期串（`#YYYYMMDD`，读者群在中国，全员同一天）；每天 1 局，当日终局后只能回看不能重开，次日新题
- 本地成绩册（无后端口径）：每日成绩历史、个人最佳、连胜天数，localStorage 持久化
- 悔棋（书 ch7 必需件）：回滚上一步，种子序列指针随之回退、重放出完全相同的牌——同种子下悔棋不破坏公平；悔棋不限次
- 规则契约文件：滑动/合并/生成/终局规则集中一处契约模块，UI 只消费纯逻辑（书稿代码块 SSOT）
- 当日局可中断续玩：局面+种子指针落 localStorage，回来接着走

## 非目标 / 反目标

- 无后端、无全网排行榜（等有部署的批次；本批拍板「骨架不配部署」）
- 不做多局/复盘/练习模式（复杂度留给后续章与后续仓）
- 不做皮肤、广告 SDK、上报埋点（ch18/19 章的内容，本仓阶段不预埋）
- 不做变异/能力块等玩法魔改（突出点只有一个，别撒胡椒面）
- 反目标：为公平竞速引入任何账号体系或中心化依赖——离线可玩是底线

## 约束

- 技术栈钉 version-lock.json：React 19 + Tailwind 4 + TS + Vite + vitest，**零新增依赖**（随机数手写 mulberry32，日期串哈希手写 FNV-1a）
- TDD：`src/lib/` 纯逻辑（种子 RNG、滑动合并、终局判定、悔棋栈、成绩册）先写失败测试再实现，无 Key 无网全绿
- 正式区纪律：过程件进 `_work/`；仓约定见 CLAUDE.md

## 方案取舍（已在对话中裁决）

- **突出点三选一**：时间回溯悔棋树 / 每日同题种子局 / 合成进化变异 → 人裁**每日同题**（公平竞速是差异化，且与教学母题最贴）
- **每天 1 局 vs 3 局**：1 局（人裁：符合书「从简单到复杂」教学坡度，ch7 取最简心智模型）
- **RNG 自写 vs 引库**：自写 mulberry32 + FNV-1a（零依赖=离线可跑+教学口径「随机也可控」）

## 视觉方向（builder 落地）

「赛事号外/竞赛日历」风：每日一期（大字题号 `#20261118`），纸面新闻纸质感（黑白+一点赛程红），成绩册做成剪报集。克制、不花哨——个性在「同题竞速」的仪式感，不在装饰堆料。

## 状态机与语义裁定（builder check 2026-11-18 收口）

以下五条为评审问出的语义空洞，按「教学最简」原则裁定，全部是本轮裁定（用户可否决）：

1. **终局语义**：死局（无路可走）是唯一终态，成绩立即落册、当日题锁定为「已完赛」；悔棋只在局中可用，死局不可复活。合成 2048 出胜利横幅但非终态，继续冲分。跨午夜进行中的局：题号按开局日锁定，残局次日仍可继续完成，未完成不记成绩。
2. **连胜定义**：连续每天「完赛」（终局落册）记 1 天，断一天清零；不要求合成 2048。当天完赛即计数，与分数无关。
3. **悔棋跨刷新有效**：持久化的是**走子日志**（方向序列），局面由种子+日志重放派生——不存棋盘快照。悔棋=日志弹出末条再重放。这也是书稿「状态可序列化」教学点的代码形态。
4. **终局回看=逐步回放**：因走子日志已持久化，回放数据零额外成本，ch7 就落简版回放（回看页：步进条+步进/暂停），不作静态死图。「同一道题怎么走的」正是每日同题的展示面，也是 ch21 回放修复的免费铺垫。
5. **「100% 断言覆盖」口径**：评审级预期——`src/lib/` 每个导出函数至少一条断言、边界用例（死局/满板合并/种子确定性）显式覆盖；不引入 coverage 包（零新增依赖），vitest 跑测试本身即门。
