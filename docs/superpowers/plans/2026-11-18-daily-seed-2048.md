# 每日同题种子局 2048 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 harness-2048 骨架写成完整可玩的每日同题种子局 2048（人人同题、每天 1 局、本地成绩册、悔棋、终局回放）。

**Architecture:** 纯逻辑层（种子 RNG / 游戏引擎 / 走子日志重放）与 UI 层分离；局面永远由「种子+走子日志」重放派生，不存棋盘快照——悔棋、续玩、回放共用同一条重放路径。

**Tech Stack:** TypeScript + React 19 + Tailwind 4 + Vite + vitest（全部钉在 version-lock.json，零新增依赖）

**Spec:** `docs/superpowers/specs/2026-11-18-daily-seed-design.md`（含五条语义裁定，本计划从它argue）

## Global Constraints

- 零新增 npm 依赖；随机数手写 mulberry32 + FNV-1a（spec 约束节）
- TDD：`src/lib/` 每个任务先红后绿；`npm test` 无 Key 无网全绿
- 100% 断言覆盖=评审级口径：`src/lib/` 每个导出函数至少一条断言，边界用例显式覆盖（spec 裁定 5）
- 死局是唯一终态，成绩落册后当日题锁定；悔棋只在局中可用（spec 裁定 1）
- 连胜=连续每天完赛，断日清零，不要求合成 2048（spec 裁定 2）
- 种子=UTC+8 日期串 `#YYYYMMDD`；跨午夜进行中的局题号锁定开局日，可继续，未完成不记成绩（spec 裁定 1）
- 零伪代码；只增不改（不动 `board.ts` 现有 `GRID_SIZE`/`emptyBoard` 签名）
- localStorage 键带 `h2048.v1.` 前缀；读取损坏 JSON 一律回退空值不抛（spec 留给 builder+Review Focus）
- 每步提交圈定文件清单，禁 `git add -A`

## Review Focus

- **午夜跨日**：UTC+8 边界（16:00 UTC 前/后）puzzleId 必须换天；进行中的残局题号锁定开局日 → Task 4 测试钉
- **无效移动**：无路可动的方向键不进日志、不消耗生成、分数不变 → Task 3 测试钉
- **满板边界**：满板但有相邻同值=可动；满板且无相邻同值=死局 → Task 3 测试钉
- **存储损坏**：localStorage 键被手改/损坏 JSON 时回退空值，页面照常起 → Task 4 测试钉
- **长局重放**：2000 步日志重放与逐步步进结果一致、性能可接受（<100ms 量级） → Task 3 测试钉

### Task 3: 游戏引擎与重放（game.ts 完成）

**Files:**
- Modify: `src/lib/game.ts`
- Test: `src/lib/game.test.ts`（追加）

**Interfaces:**
- Consumes: Task 1 `createDailyRng`；Task 2 `DIRECTIONS`/`SPAWN_VALUES`/`slideLine`
- Produces:
  - `interface GameState { cells: number[][]; score: number; spawns: number; won: boolean; dead: boolean }`（cells 行=列序，0=空）
  - `initialState(puzzleId: string): GameState`（空盘 + 连续两次生成，spawns=2）
  - `applyMove(state: GameState, dir: Direction, puzzleId: string): { state: GameState; moved: boolean }`（内部用 createDailyRng(puzzleId) 重建流并快进 spawns 次后取生成——与 replay 同一条生成路径）

  - `isDead(cells: number[][]): boolean`（满板且无横竖相邻同值=死局；导出以便直测满板边界）
  - `maxTile(state: GameState): number`
